# New JellyCat Species Template

1. Copy this `_template` directory and rename it to the new `species_id`.
2. Add `stages/stage_1.png` through `stages/stage_5.png`.
3. Add the same `species_id` to `data/species.json`.
4. Add its stage requirements to `data/evolution.json`.
5. Add an egg asset under `assets/eggs/<species_id>/` when egg selection supports the species.

Missing species stage art falls back to `normal_jellycat` at the same stage.
