# JellyCat Character Standard

## Identity invariant

A JellyCat must remain recognizable as both:

- a jellyfish-like floating body
- a cat-like character with clear facial identity

Neither side should completely erase the other.

## Base form guidance

- rounded or domed jelly body
- expressive cat face placed consistently on the main body
- soft tentacles / trailing appendages
- compact silhouette suitable for multiple simultaneous creatures on screen
- readable at gameplay scale

## Expression system

Expressions should survive downscaling. Prioritize eyes, mouth, ear / silhouette cues, and body posture over tiny facial details.

Recommended production states include:

- neutral
- happy
- touched / pleased
- hungry
- eating
- sick / low-energy
- recovering
- sleeping / resting

## Variant rule

Color or species variants may alter palette, small silhouette accents, patterning, and tentacle styling, but should retain the base readability rules unless a new species is intentionally designed.

## Multi-character rule

Because multiple JellyCats may inhabit the same aquarium, individual assets must avoid excessive footprint and visual effects. Character spacing and silhouette separation matter more than hero-character composition.

## Editing rule

When editing an approved JellyCat reference, explicitly lock:

- face identity
- body proportions
- tentacle count / structure when established
- palette when established
- camera / orientation when matching animation frames

Change only the requested property unless a redesign is explicitly requested.
