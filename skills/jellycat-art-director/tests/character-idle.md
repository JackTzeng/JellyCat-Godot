# Test: Base JellyCat Idle Float

## Request

Generate a transparent idle-floating animation for the base JellyCat for Godot gameplay use.

## Expected resolution

The skill should produce an Asset Specification before generation and should resolve:

- sprite animation
- transparent background
- 6–8 frame or equivalent loop plan
- stable canvas / scale / anchor
- subtle vertical drift
- soft squash / stretch
- delayed tentacle follow-through
- no aquarium background baked into frames
- visual QA after generation

## Failure examples

- different character proportions between frames
- opaque background
- dramatic swimming instead of idle float
- positional jitter
- hard plastic appearance
